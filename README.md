# Prog-Web-I-UFCG

Repositório com os exercícios, roteiros de laboratório e projetos desenvolvidos na disciplina **Programação para Web I** da Universidade Federal de Campina Grande (UFCG).

O conteúdo evolui progressivamente de páginas estáticas em HTML/CSS até uma aplicação React completa, acompanhando os tópicos trabalhados ao longo da disciplina: marcação e estilização, formulários, manipulação de DOM, JavaScript e, por fim, uma SPA em React.

## Estrutura do repositório

```
.
├── Exercicios/       # Exercícios avulsos de HTML/CSS
└── Roteiros/         # Roteiros práticos de laboratório (1 a 8)
```

## Destaque: Roteiro 8 — Dashboard em React

O roteiro final consiste em uma aplicação React construída sobre o template [Material Dashboard 2 React](https://github.com/creativetimofficial/material-dashboard-react), customizada com telas próprias de **Alunos** e **Disciplinas**.

### Como executar

```bash
cd Roteiros/Roteiro8/material-dashboard-react-main
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.

## Tecnologias utilizadas

- HTML5 e CSS3
- JavaScript (DOM, eventos, funções)
- React e Material UI (MUI)
